# Tarkov-moa — Tarkov Map of Action

A quest-aware interactive map companion for Escape from Tarkov. It shows only the
points of interest relevant to your currently active quests, syncing progress
passively from the game's local logs.

## Install

Grab the latest `*-setup.exe` from [Releases](https://github.com/mopocop/Tarkov-moa/releases).
Install it once — from then on the app updates itself automatically.
